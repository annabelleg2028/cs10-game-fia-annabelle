

## Grey Whale Migration

**Group Members:** Annabelle, Fia
## Description

This is a game following the migration of a grey whale, and the player sees the hardships that the whale faces, such as pollution, fishing boat harm and limited food access. It is a perfect difficulty level as it is doable for a player to get through 2/3 of the game in the first attemps, but actually winning would take many tries so there is a good mix of instant gradification and difficulty that the player has to overcome.

## Justification

When making our game we made some edits to our origional plan to improve gameplay and flow. On of the biggest changes we made was getting rid of the fishing boat that competed with the player to capture tokens. This was because we wanted the game to center around the whale and it's struggle to migrate instead of a competition with another more animate part of the game. We belived that having a fishing boat would take away emphasis on how difficult the migration itself was. Additionally we removed the time rush because we realized that the whale would move at a consistant pace regardless of player action so this would not make sense. We also decided that when the player died they would not retry the level from the start and instead restart the game because it made the game more challenging and improved game flow. We also did not use different colors for the levels because it did not match the aesthetic to have water that was a strange color.
